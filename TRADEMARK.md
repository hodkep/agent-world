# Agent World name and logo

The code of Agent World is licensed under the [Apache License 2.0](LICENSE). That license, like any open source license, does **not** give anyone the right to use the project's name or logo (section 6 of the license says so in as many words). This page says what is and is not fine.

"Agent World", the pixel banner, the app icon and the figures in the artwork are the project's identifying marks. They are not registered trademarks; this is a statement of how the project asks them to be used.

## Fine, with no need to ask

- Saying what your work is: "a fork of Agent World", "based on Agent World", "works with Agent World".
- Writing about the project, linking to it, and showing screenshots in reviews, articles and talks.
- Using the name in a package or repository name only when it is plainly a fork or an integration, such as `agent-world-fork` or `agent-world-plugin-x`, and the README says so.

## Please do not

- Ship a modified build under the name "Agent World", or with the project's icon or banner. A modified build needs its own name and its own artwork.
- Present a fork, a service or a product as the official Agent World, or as endorsed by its author.
- Use the name or logo so that someone could reasonably think your product is this one.
