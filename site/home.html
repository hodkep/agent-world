The screening room

Fifty-two seconds: every agent on its own branch, plans that wait for your word, and the whole office at a glance. With a voiceover, so turn the sound up.

The workroom

Each character does what its agent does: thinking, researching, implementing, running, delegating or waiting. Click one to open its chat: tool cards, edits as diffs, a Code tab for changes and history.

The meeting table

Workflows with plan and review gates: the agent writes a plan you approve, builds it, walks you through the change, and lands it only when you press Run. A run is a track in the chat; the station it stands on is where the work is.

WorkflowsTodos

The bookshelf

Skills, instructions and prompts live in one library, and a playbook says when each applies. An agent reads the item before the work it covers, and the office shows it at the shelf while it does.

Library and playbook

Make it yours

Ask an agent to restyle the app: themes, layouts and icons, and little widgets that show live data such as a price or the weather. You keep it, or undo it.

The loading dock

  1. Download. The arm64 dmg for Apple silicon, the x64 one for Intel. Faster from the mirror: arm64, x64.
  2. Open Anyway. macOS 15 and later: System Settings › Privacy & Security. Homebrew skips this step.
  3. Sign in once. Setup installs Claude Code and has you sign in, in a terminal inside the app.
  4. Hire. Pick a folder, name an agent, choose a role and a model. It gets its own git branch.
