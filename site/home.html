Your agents, at their desks

Run your coding agents from one pixel-art office. Each agent has its own git branch and a real Claude Code or Antigravity session. You see who is thinking, running or waiting for you, and step in from the office.

Download for MacInstall notes

brew install --cask hodkep/tap/agent-world

Why it is different

Control over spectacle

Every visual state maps to a real agent state you can act on.

Own the session

The app launches and hooks the agents it shows. Your claude stays unmodified, and nothing global is changed.

Never lose work

Uncommitted changes block removal. Nothing is deleted silently.

See it work

The office

Each character does what its agent does: thinking, researching, implementing, running, delegating or waiting. Click one to open its chat.

Install in four steps

1 · Download

The arm64 dmg for Apple silicon, the x64 one for Intel.

2 · Open Anyway

macOS 15 and later: System Settings › Privacy & Security. Homebrew skips this step.

3 · Sign in once

Setup installs Claude Code and has you sign in, in a terminal inside the app.
